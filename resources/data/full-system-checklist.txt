Checklist พัฒนา CMS และระบบโรงเรียนครบระบบ
วันที่ 5 พฤศจิกายน 2569

ใช้เป็นร่างขอบเขตการเขียนโค้ดและการตรวจรับ ไม่ใช่สถานะว่าโมดูลทั้งหมดใช้งานจริงแล้ว
[x] = โค้ดและผลทดสอบในเครื่อง; [ ] = งานที่ต้องทำ/ตรวจรับ; ทุกโมดูลยังต้องผ่านเกณฑ์ตรวจรับรวม

ลำดับที่แนะนำ: P0 ฐานระบบ → P1 CMS → P2 งานประจำวัน → P3 วัดผล/รายงาน → P4 ระบบเสริม → P5 ย้าย/แจกใช้งาน

เกณฑ์เสร็จของทุกโมดูล
- Requirement และข้อยกเว้นได้รับการยืนยันจากเจ้าของงานของโรงเรียน
- มี migration/model/domain/API/UI และ validation ครบตามเส้นทางสำเร็จ/ล้มเหลว
- ตรวจ role/school/year/data scope รวม private media/export ทุกเส้นทาง
- Mutation สำคัญเป็น transaction มี version/idempotency/audit ตามความจำเป็น
- Tests และ HTTP บน target จริงผ่าน พร้อมทดสอบกู้คืน/rollback ที่เกี่ยวข้อง
- มือถือ/คีย์บอร์ด/ข้อความผิดพลาดและเอกสารผู้ใช้ตรวจแล้ว
- ผู้ใช้ตรวจรับด้วยข้อมูลตัวอย่างจริงที่ได้รับอนุญาต และระบุผู้รับผิดชอบหลังเปิดใช้

M01 เว็บไซต์ ข่าว เมนู และสื่อ
P1 | ต้องมี: M02
ขอบเขตจากแหล่งอ้างอิง: หน้าเนื้อหา ข่าว/กิจกรรม ผลงาน จดหมายข่าว อัลบั้ม เอกสาร แบนเนอร์ ป๊อบอัพ เค้าโครงหน้าแรก และสิทธิ์ผู้ดูแล
เกณฑ์ปลายทาง: ย้ายเนื้อหา รูป เอกสาร และ URL เดิม; ข่าวและบุคลากรเผยแพร่ได้ตามสิทธิ์
 [x] M01.01 เลือกธีม 3 แบบ ปรับสี ชื่อ โลโก้ ภาพต้อนรับ ฟอนต์ และรูปแบบข่าวโดยไม่แก้โค้ด
 [x] M01.02 ดูตัวอย่างธีมจาก template หน้าบ้านจริงและแยกร่างจากธีมเผยแพร่
 [x] M01.03 เขียนข่าว หัวข้อ/รูป/เนื้อหาในหน้าเดียว พร้อมคำโปรยและ URL อัตโนมัติ
 [x] M01.04 เก็บร่างแก้ไขข่าวโดยไม่เปลี่ยนข่าวที่เผยแพร่ และบันทึก publication snapshot
 [x] M01.05 อัปโหลด JPEG/PNG/WebP ตรวจชนิด/ขนาด จัดเก็บ private และเผยเฉพาะภาพที่ใช้ในเนื้อหาเผยแพร่
 [x] M01.06 เลือกหมวดข่าวคงที่ ปักหมุด และกรองข่าวหน้าบ้าน
 [x] M01.07 สร้างหน้าอิสระ เช่น ประวัติ วิสัยทัศน์ โครงสร้าง บุคลากร หลักสูตร และข้อมูลติดต่อ
     ทำแล้ว 12 ประเภท: ข่าว หน้าเนื้อหา รับสมัครงาน ประกาศจัดซื้อจัดจ้าง อัลบั้ม ดาวน์โหลด บุคลากร กิจกรรม แบนเนอร์ บริการ วิดีโอ และจดหมายข่าว
 [x] M01.08 ตัวจัดหน้าแรกแบบ block: เพิ่ม ซ่อน เรียง และคืนแบบเดิมได้ โดยไม่ต้องเขียน HTML/CSS
     เพิ่มบล็อกจากหน้าที่เผยแพร่ ซ่อน/เรียงส่วนเนื้อหา คืนรูปแบบมาตรฐาน และแยกร่างจากหน้าเว็บจริงได้แล้ว
 [x] M01.09 เมนูหลายระดับ ลากเรียง เมนูแยกตามตำแหน่ง และตรวจลิงก์เสีย
     เมนู 3 ระดับ ลากทั้งกลุ่ม ปุ่มขึ้น/ลง/เยื้อง header/footer/utility; ตรวจลิงก์ภายใน ไม่ร้องขอ URL ภายนอกจาก server
 [x] M01.10 จัดการหมวด/แท็กเอง ค้นข่าว ตั้งเวลาเผยแพร่ และกำหนดวันสิ้นสุดประกาศ
     หมวดแก้ไขได้ แท็ก ค้นหา ตั้งเวลาพร้อมตรวจบัญชีผู้เผยแพร่ และวันเริ่ม/สิ้นสุดประกาศ
 [x] M01.11 Rich text ที่กรอง HTML แนบ PDF อัลบั้มภาพ วิดีโอและจดหมายข่าว
     Rich text ที่กรอง HTML เอกสาร อัลบั้ม วิดีโอ YouTube/Vimeo แบบกดยินยอมโหลด และจดหมายข่าวพร้อมฉบับ/ช่วงเวลา
 [x] M01.12 แบนเนอร์ สไลด์ ป๊อบอัพ ประกาศด่วน ปฏิทิน และลิงก์บริการโรงเรียน
     ทำแล้ว: แถบประกาศ สไลด์กดเลื่อน ป๊อบอัพครั้งเดียวต่อ session ปฏิทิน และลิงก์บริการ
 [x] M01.13 คลังสื่อมีค้นหา โฟลเดอร์ alt text crop/resize/optimize และตรวจสื่อที่ยังถูกใช้อยู่ก่อนลบ
     คลังสื่อ ค้นหา โฟลเดอร์ alt สร้างสำเนา crop/resize/WebP/JPEG/PNG คงต้นฉบับ และห้ามลบสื่อที่ร่าง/ธีม/ประวัติยังใช้; ทดสอบเลือกหลายไฟล์และ retry รายไฟล์จริง
 [x] M01.14 ยกเลิกเผยแพร่ ถังขยะ กู้คืน และหน้าเปรียบเทียบ/คืน publication revision
     หยุดเผยแพร่ ถังขยะ คืนเป็นร่าง เปรียบเทียบหัวข้อ/คำโปรย/ข้อความสองรุ่น และคืน publication revision โดยไม่เปลี่ยนหน้าที่เผยแพร่ทันที
 [x] M01.15 SEO/OG, favicon, sitemap, canonical URL, redirects และค้นหาหน้าบ้าน
     SEO/OG favicon sitemap canonical ค้นหา และ redirect 301/302 แบบตรวจ version/วงวน รวม query fallback
 [x] M01.16 แบบฟอร์มติดต่อ/ดาวน์โหลด มีป้องกัน spam และกำหนดเจ้าของข้อมูล
     กล่องติดต่อและ PDF แยกตามโรงเรียน ตรวจ CSRF/ยินยอม/honeypot/rate limit และไม่มีการส่งอีเมลออกภายนอก
 [ ] M01.17 ทดสอบให้ครูเปลี่ยนธีมและโพสต์จากมือถือได้เอง โดยข่าว/รูป/URL ไม่สูญหาย
     ตรวจหน้าจอ 390px และการเผยแพร่โดย agent แล้ว แต่ยังไม่มีครูของโรงเรียนทำ UAT
 [x] M01.18 Hero slide แก้ข้อความ/ภาพคอมและมือถือ/ปุ่ม/จุดโฟกัส/ลำดับ/วันเวลา มีหยุด เล่น คีย์บอร์ด และ reduced motion
 [x] M01.19 ธีม 3 ชุดพร้อม GPT icon 27 รูปและ banner 3 รูป เพิ่ม theme package ผ่าน config ได้ favicon และโหมดสว่าง/มืด/ตามระบบ
 [x] M01.20 ประกาศพิเศษไว้ทุกข์/เฉลิมฉลองเกือบเต็มจอ ปิดด้วยปุ่มหรือ Escape ตั้งวันเวลาและความถี่ ค่าเริ่มต้นปิด
 [x] M01.21 เลขอารบิก 0–9 บนเว็บและ CMS รวมวันที่ ปี พ.ศ. และประกาศจัดซื้อจัดจ้าง; ไม่เพิ่มระบบร่างเอกสารจัดซื้อจัดจ้าง
 [x] M01.22 ปรับ layout กระชับสำหรับภาษาไทย: ฟอนต์อ่านง่าย สไลด์เตี้ย ข่าวคู่ประกาศ dashboard 12 หมวด ฟอร์มสองคอลัมน์ และรายละเอียดพับเปิดได้
 [x] M01.23 หน้ารวมข้อมูล 12 ประเภทและตรวจ 72 เมนูหลังบ้าน จับคู่จุดแสดงผล แยกข้อมูลภายใน/ตัวอย่าง/แผน แสดงพันธกิจและเวลากิจกรรมที่แก้จาก CMS

M02 บัญชี สิทธิ์ และขอบเขตข้อมูล
P0 | ต้องมี: ฐานข้อมูลและ framework
ขอบเขตจากแหล่งอ้างอิง: รองรับงานผู้บริหาร หัวหน้าฝ่าย ครูประจำชั้น วิชาการสายชั้น หัวหน้าบูรณาการ และสิทธิ์รายหน้า/รายบุคคล
เกณฑ์ปลายทาง: ทดสอบสิทธิ์แยกห้อง สายชั้น รายวิชา เจ้าของแฟ้ม และหน้าที่อนุมัติทั้ง API และไฟล์
 [x] M02.01 Email/password login, logout, login rate limit และแยกบัญชีสาธิตจากบัญชีจริง
 [x] M02.02 สร้างผู้ดูแลคนแรกผ่านคำสั่ง interactive โดยไม่ต้อง seed ข้อมูลนักเรียน
 [x] M02.03 เพิ่ม แก้ ปิดผู้ใช้ แยก admin/editor/principal/teacher และตรวจ school scope
 [x] M02.04 เปลี่ยนรหัสผ่าน ถอน session เก่าหลังเปลี่ยนสิทธิ์/รหัสผ่าน และห้ามปิด admin คนสุดท้าย
 [x] M02.05 ห้าม editor เข้าทุก API งานโรงเรียน แม้ถูกผูกข้อมูลครู/ห้องไว้
 [x] M02.06 ตรวจ version ก่อนเขียนทับ และบันทึก audit ของ mutation ใน transaction
 [ ] M02.07 Permission รายการกระทำ แยกอ่าน/เขียน/เผยแพร่/อนุมัติ/ส่งออก และขอบเขตชั้น/ห้อง/รายวิชา
 [ ] M02.08 เชิญผู้ใช้ กู้รหัสผ่าน ยืนยันอีเมล และ MFA สำหรับบทบาทที่โรงเรียนกำหนด
 [ ] M02.09 หน้าดู/ถอน session อุปกรณ์ บันทึกการเข้าใช้ และตรวจประวัติเปลี่ยนสิทธิ์
 [ ] M02.10 Delegation ผู้รักษาการ วันหมดอายุสิทธิ์ และทดสอบ deny-by-default ทุกโมดูล
 [ ] M02.11 ทดสอบหลายโรงเรียน หลายปีการศึกษา และป้องกัน direct-object access ทั้งไฟล์และ export

M03 ทะเบียนนักเรียนและผู้ปกครอง
P2 | ต้องมี: M02
ขอบเขตจากแหล่งอ้างอิง: ข้อมูลตัวตน ห้อง/เลขที่ ประวัติครอบครัว ที่อยู่ สุขภาพ พิกัด และติดตามศึกษาต่อ ป.6
เกณฑ์ปลายทาง: นับรายการและผูกบุคคล/ปี/ห้องได้โดยไม่ใช้เลขประชาชนเป็น primary key; ตรวจซ้ำและความสัมพันธ์ก่อนนำเข้า
 [ ] M03.01 CRUD ทะเบียนนักเรียน รหัส สถานะ รูป และข้อมูลผู้ปกครองหลายคนพร้อมความสัมพันธ์
 [ ] M03.02 ปีการศึกษา ห้อง สายชั้น แผนการเรียน และประวัติย้ายห้อง/ย้ายเข้า/ออก/จบการศึกษา
 [ ] M03.03 นำเข้า CSV/Excel พร้อม preview ตรวจซ้ำ รายการผิดพลาด และ rollback batch
 [ ] M03.04 ค้นหาและส่งออกตามสิทธิ์ โดยไม่ปะปนข้อมูลปีเก่า/โรงเรียนอื่น
 [ ] M03.05 รับสมัคร ตรวจเอกสาร และส่งต่อเป็นทะเบียนโดยยืนยันเจ้าหน้าที่ก่อนบันทึก
 [ ] M03.06 ตรวจคุณภาพข้อมูล อัปเดตผู้ปกครองและประวัติแก้ไข โดยจำกัดข้อมูลอ่อนไหว
 [ ] M03.07 แบบข้อมูลไทย/ต่างชาติ/ไร้สัญชาติ: ชื่อหลายภาษา ชื่อเดี่ยว ความละเอียดวันเกิด สัญชาติแยกประเภทเอกสาร และเลข G Code ที่หน่วยงานออก
 [ ] M03.08 ผู้ปกครองหลายคน/นักเรียนหลายคน แยกความสัมพันธ์ อำนาจปกครอง ผู้รับส่งและผู้ติดต่อฉุกเฉิน พร้อมประวัติและขอบเขตสิทธิ์
 [ ] M03.09 โทรศัพท์หลายประเทศ ที่อยู่ทะเบียน/ปัจจุบัน/ติดต่อ ภาษา ล่าม LINE และ social ที่ให้ข้อมูลโดยสมัครใจ ไม่เก็บรหัสผ่าน
 [ ] M03.10 คลังเอกสารระบุตัวตน private แยกจาก CMS: quarantine/AV/encryption/version/redaction/สิทธิ์อ่านดาวน์โหลด/audit/retention
 [ ] M03.11 นำเข้า/export และคำขอแก้ไขผ่านเจ้าหน้าที่ ไม่ตัดสิทธิ์เข้าเรียนอัตโนมัติจากเอกสารขาดหรือหมดอายุ
 [ ] M03.12 ทดสอบ 35 กรณีจากแบบทะเบียน 2026-11-05 รวม school scope และข้อมูลเด็ก; ปัจจุบันเป็นแบบออกแบบ ยังไม่รับข้อมูลจริง

M04 เช็คเวลาเรียนและรายงานการมาเรียน
P2 | ต้องมี: M03, M08
ขอบเขตจากแหล่งอ้างอิง: บันทึกขาด ลา มาสาย รายงานรายห้อง/วัน/ช่วงเวลา และส่งข้อมูลเข้าสมุดประเมิน
เกณฑ์ปลายทาง: ผลรวมสถานะและการนับวันตรงรายงานเดิม; ปฏิทินและวันหยุดกำหนดได้
 [x] M04.01 บันทึกการมาเรียนเป็น batch ตามห้อง ตรวจขอบเขตครูและ rollback เมื่อมีรายการผิด
 [ ] M04.02 เวลาเรียนรายวัน/รายคาบ ปฏิทินวันเรียน หยุด/ลา/สาย และวันเรียนทดแทน
 [ ] M04.03 กติกาแก้ย้อนหลัง เหตุผลแก้ไข ปิดงวด และประวัติการแก้ของครู
 [ ] M04.04 สรุปขาด/ลา/สายรายคน ห้อง ชั้น เดือนและภาคเรียนตามสูตรโรงเรียน
 [ ] M04.05 แจ้งผู้ปกครองผ่านช่องทางที่เปิดใช้และได้รับอนุญาต พร้อม retry/สถานะส่ง
 [ ] M04.06 ตรวจยอดเวลาเรียนกับวัดผลและรายงานที่โรงเรียนใช้จริง

M05 พฤติกรรมและการดูแลช่วยเหลือ
P2 | ต้องมี: M03, M04
ขอบเขตจากแหล่งอ้างอิง: รายงานพฤติกรรมรายวัน ตัดคะแนน แนบหลักฐาน และติดตามพฤติกรรมตามขอบเขตผู้ดูแล
เกณฑ์ปลายทาง: รักษาประวัติ เหตุผล ผู้บันทึก และสิทธิ์รายห้อง; แก้ข้อมูลมี audit trail
 [ ] M05.01 บันทึกพฤติกรรม เหตุการณ์ หลักฐาน ผู้รับผิดชอบและสถานะติดตาม
 [ ] M05.02 ตั้งเกณฑ์คะแนน/ระดับตามโรงเรียนพร้อม version และสิทธิ์แก้ไข
